# PTM Manager

Internal unified application suite for Palm Tree Marine Pvt Ltd.

## Current release
PTM Manager v2.1.1 — Customer Visibility Hardening

This repository is private source control for Manager, Warranty Manager, and Quotation Manager.

## Production safety
Do not commit production databases, SQLCipher/DPAPI material, passwords, session secrets, Telegram tokens, OneDrive credentials, private keys, CA private keys, backups, or certificates containing private keys.

Stable infrastructure (Caddy, DNS, TLS/CA, Tailscale and production ports) is intentionally kept outside normal application release changes.
