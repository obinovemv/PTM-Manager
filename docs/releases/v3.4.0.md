# PTM Manager v3.4.0 — ONE WORKSPACE

Structural unification release.

- Quotation now ships its own platform-controlled base shell in the release payload instead of relying on an older independently installed shell.
- Warranty and Quotation use the same navigation geometry, sidebar width, topbar height, content width, workspace spacing, record spacing and responsive breakpoints.
- Module navigation is restricted to module operations plus PTM Home and centralized Administration.
- Shared gallery geometry is enforced at the platform layer; Quotation cannot override a single customer image into a full-width card.
- Warranty and Quotation record detail pages explicitly consume the `ptm-one-workspace` primitive.
- Installer deploys the Quotation base shell and shared platform stylesheet to all applications.
- Verification now includes structural ONE WORKSPACE checks, not only presence of shared CSS classes.
- Business workflows and terminology remain module-specific.
- Rule: **One PTM Platform. One Design System. Multiple Business Workflows.**
