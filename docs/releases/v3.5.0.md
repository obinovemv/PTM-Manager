# PTM Manager v3.5.0 — Unified Record Workspace

This release turns the 3.x platform contract into a stricter record-workspace contract.

## Canonical workspace
Warranty and Quotation use the same record navigation and geometry:
- Overview
- Updates
- Timeline
- Files

The PTM Platform owns record navigation, spacing, cards, metric strips, two-column record grids, file-card geometry and responsive behavior. Modules own business data, terminology and workflow.

## Fixes
- Quotation global search now targets the real `request_search` Flask endpoint and handles the endpoint array response, preventing the v3.4 BuildError regression.
- Quotation no longer exposes overlapping `Files` and `All Files` top-level concepts.
- Warranty no longer exposes a different Evidence/Documents top-level navigation structure.
- Warranty and Quotation galleries consume the same compact platform file primitives.
- File cards are bounded on desktop and use a controlled two-column responsive mobile grid.
- Versions are synchronized to 3.5.0 across Manager, Warranty and Quotation.
- Verification rejects workspace navigation drift, gallery drift, template parse failures and the known Quotation search-route regression.

## Platform direction
One PTM Platform. One Design System. Multiple Business Workflows.

Administration remains centralized in Manager. Customer/Sales publication remains explicit and internal PTM/supplier operational content remains separate.

No Caddy, DNS, TLS leaf certificate, Tailscale, port or business-database changes are included.
