# PTM Manager v2.1.1 — Customer Visibility Hardening

Built from v2.1.0 Customer Communication Workflow.

## Fixes
- Sales Case Health no longer derives customer follow-up from the internal case next-action date.
- Sales Customer Update Summary no longer falls back to internal remarks, supplier text, or internal follow-up state.
- Customer follow-up is sourced only from the latest Manager/Admin-approved Customer/Sales update.
- Added customer-safe status and customer-safe next-action fields to approved customer updates.
- Copy Customer Update is disabled until an approved customer message exists.
- Copy Customer Update now generates a customer-ready warranty message from approved Customer/Sales data only.
- Sales-created customer communications no longer overwrite internal Warranty next-action/follow-up fields.
- Existing visibility filtering and 403 attachment authorization remain enforced.
- Schema migration is additive and idempotent.

## Production baseline
v2.1.0 was the previous deployed build. Install v2.1.1 using the packaged Boot-Safe installer and verify Sales/Manager views before marking stable.
