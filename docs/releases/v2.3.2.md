# PTM Manager v2.3.2 — Verified Caddy Device Trust

## Root cause
The live PTM HTTPS sites are issued by Caddy Local Authority - ECC Intermediate, chaining to Caddy Local Authority - 2026 ECC Root. Earlier Device Setup could publish an unrelated legacy PTM Root CA, so iOS/Brave could remain Not Secure even after installing the profile.

## Verified trust source
- Subject: Caddy Local Authority - 2026 ECC Root
- Thumbprint: E26E71444DF85E3C5B150CE865084F85C0F6B671
- Source: %APPDATA%\Caddy\pki\authorities\local\root.crt
- Validity observed: 03 Sep 2026 through 12 Jul 2036

## Fix
- Installer always replaces the published Device Setup CA with the live Caddy public root.
- Installer refuses to publish the CA if its thumbprint or subject does not match the verified live root.
- No root/intermediate/server private key is copied or distributed.
- Device Trust Center verifies the published certificate thumbprint before enabling downloads.
- Windows setup installs the same root machine-wide and validates trusted HTTPS for manager.ptm.local, warranty.ptm.local and quotation.ptm.local.
- Apple profile now contains the exact Caddy root used by the live sites and clearly identifies it as Caddy Local Authority - 2026 ECC Root.
- Android download uses the same verified public root.
- Warranty and Quotation continue to route Device & Security to the centralized Manager trust center.

## iPhone/iPad
For manually installed profiles, enable Full Trust for Caddy Local Authority - 2026 ECC Root under Settings > General > About > Certificate Trust Settings, then fully close and reopen the browser.

## Infrastructure
No Caddy configuration, DNS, TLS leaf certificate, Tailscale, port or business database changes.
