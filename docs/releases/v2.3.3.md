# PTM Manager v2.3.3 — Unified Administration Experience

## What was wrong
Administration had become centralized logically but not visually or navigationally. PTM Home exposed Administration twice, Users & Access still used the old App Selector header, Device Setup had a separate Back to Manager header, and Audit/System pages had their own navigation. System Settings was also only a placeholder that duplicated the Administration concept without providing real settings.

## Fix
- PTM Home now uses the Administration application card as the single Administration entry point; the duplicate top Administration link is removed.
- Every Administration page uses one consistent shell and navigation: Administration, Users & Access, Audit Log, Device & Security, System Health, PTM Home, Logout.
- /admin is always the Administration control-center home.
- Canonical routes added for /admin/users and /admin/device-security while legacy routes remain compatible.
- User add/edit/reset screens stay inside the Administration shell.
- System Settings is removed from the Administration navigation/home until there are actual centralized settings to manage; /admin/settings redirects to /admin.
- Device & Security no longer has a separate 'Back to Manager' experience.
- System Health labels the certificate state as the verified Caddy root rather than the obsolete PTM Root CA wording.
- Administration home is reduced to four real platform functions: Access, Audit, Device Trust, Health.

## Infrastructure
No Caddy, DNS, TLS leaf certificate, Tailscale, port or business database changes.
