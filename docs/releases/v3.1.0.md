# PTM Manager v3.1.0 — Shared Workspace

Phase 2 of the PTM Manager 3.x platform work.

- Strengthens the shared platform layer used by Warranty and Quotation.
- Standardizes workspace spacing, record density, action hierarchy, form controls and Sales-facing cards.
- Enforces one compact gallery geometry across Warranty Evidence and Quotation Customer Files; a single file cannot stretch to page width.
- Keeps desktop, half-window and mobile behavior under shared platform rules.
- Adds v3.1 shared-workspace regression checks to the installer verification suite.
- Retains the rule: **Uniform platform, specialized workflows.**
- No Caddy, DNS, TLS leaf certificate, Tailscale or port changes.
