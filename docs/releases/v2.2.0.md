# PTM Manager v2.2.0 — Unified UX Architecture

Major presentation-layer overhaul built on the stable v2.1.4 backend/security baseline.

## Unified experience
- Next-generation visual system across Manager Portal, Warranty and Quotation.
- Bounded readable workspaces on large displays instead of edge-to-edge stretching.
- Stronger hierarchy, spacing, card language, form controls, focus states and action placement.
- Deliberate desktop, half-window, tablet and mobile behavior.
- Reduced-motion handling and stronger keyboard-focus visibility.

## Warranty
- Sticky case workspace navigation: Overview, Timeline, Evidence, Updates/Customer and Documents where permitted.
- Existing v2.1.4 evidence visibility, linked-folder discovery, deduplication and Sales authorization retained.
- Customer communication workflow and role boundary retained.
- Evidence grid and case metadata adapt intentionally across viewport sizes.

## Quotation
- Matching workspace architecture with Overview, Timeline, Documents and Updates navigation.
- Responsive forms, milestones, documents and timeline reading widths.
- Role-specific quotation workflow preserved.

## Manager Portal
- Refined responsive dashboard, application cards, attention queue and search.
- Improved information density on desktop and mobile reflow.

## Accessibility baseline
Design changes follow WCAG 2.2-oriented principles: visible focus, practical target sizing, responsive reflow, consistent navigation and reduced motion.

## Infrastructure
No intended changes to Caddy, DNS, TLS, Tailscale, ports or business databases. Boot-Safe Supervision retained.
