# PTM Manager v2.3.1 — Unified Administration & Audit Fix

## Administration UX
- Administration on PTM Home is now a first-class application card for Admin users.
- /admin now opens a dedicated Administration control center instead of redirecting directly to System Health.
- Central Administration presents Users & Access, Unified Audit Log, System Settings, Device & Security, and System Health as one coherent workspace.

## Audit Log fix
- Fixed a concrete Manager audit schema mismatch: manager_audit stores detail, while v2.3.0 queried details, causing /admin/audit to fail.
- Unified audit reader now handles legacy Warranty/Quotation audit schema variations defensively using table/column introspection.
- Audit module filters have active state and the page remains usable when an individual module audit source is unavailable.

## Platform model
PTM Manager remains the platform/control plane; Warranty and Quotation remain operational modules.

## Infrastructure
No Caddy, DNS, TLS, Tailscale, port or business database changes.
