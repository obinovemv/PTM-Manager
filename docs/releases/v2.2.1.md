# PTM Manager v2.2.1 — Complete UX Overhaul

This release replaces the remaining wrap-only responsive behavior with adaptive interaction patterns across Warranty, Quotation and the Manager Portal.

## Warranty
- Case header rebuilt as a bounded operational header rather than an edge-to-edge action strip.
- Primary action hierarchy: Copy Case Table remains primary; Edit and Draft Email are secondary; PDFs, closure and destructive actions move into Documents & More.
- At half-window/tablet widths, secondary actions collapse instead of wrapping into awkward multi-row button grids.
- Mobile uses a primary action plus compact overflow menu.
- Redundant case badges are reduced: Normal priority is hidden and duplicate action/health signals are consolidated.
- Forms, composer, state controls and evidence upload deliberately become one-column on mobile.
- Evidence remains two-column where practical on phones and responsive on larger displays.
- Existing role, evidence visibility and customer communication security retained.

## Quotation
- Matching bounded 1320px workspace.
- Responsive milestones, documents, forms, updates and timeline.
- Half-window and mobile behavior reflows intentionally rather than squeezing desktop grids.

## Manager Portal / Administration
- Tighter readable workspace and information density.
- Adaptive application and attention layouts.
- Mobile-first reflow for attention rows and administration forms.
- Consistent focus treatment and control sizing.

## Infrastructure
No Caddy, DNS, TLS, Tailscale or port changes. Boot-Safe Supervision retained.
