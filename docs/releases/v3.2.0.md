# PTM Manager v3.2.0 — Shared Records

Phase 3 of PTM Manager 3.x.

- Introduces semantic shared platform primitives for record headers, metric strips, information grids, registers, filter bars and activity streams.
- Warranty and Quotation record pages now consume the same record-header and metric-strip platform classes.
- Quotation Register now consumes the shared register shell/filter/register-row primitives.
- Responsive behavior for these primitives is centralized in the PTM platform stylesheet.
- Retains shared gallery geometry, live Sales view, Responsible Sales, unified Administration and verified Caddy trust.
- Adds shared-record regression checks to the installer verification gate.
- Rule remains: **Uniform platform, specialized workflows.**
