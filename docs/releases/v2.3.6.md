# PTM Manager v2.3.6 — Sales Workflow & Live Sales View

- Adds **View as Sales** to Warranty and Quotation for Admin/Manager. It uses the same Sales-filtered data path and is read-only while previewing.
- Quotation now requires **Responsible Sales** on new Admin/Manager requests and exposes the same field in Edit Request.
- Adds a dedicated **Update Sales** composer to Quotation for publishing the exact customer-safe message Sales should copy and send.
- Quotation Sales view keeps customer communication/follow-up separate from internal/supplier updates.
- Fixes Copy Customer Update selection so Sales responses cannot become the next approved PTM message.
- Renames quotation attachment language to **Files / Customer Files** rather than Warranty-specific Evidence terminology.
- Customer file thumbnails are reduced to Warranty-like compact gallery density.
- Existing unified Administration and verified Caddy Device Trust architecture is retained.
- No Caddy, DNS, TLS leaf certificate, Tailscale, port or business database replacement changes.
