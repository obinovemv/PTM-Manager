# PTM Manager v2.3.0 — Unified Platform Architecture

Major architecture cleanup built on v2.2.2.

## Main PTM Manager owns platform administration
- Users & Access remains centralized in Manager and controls Warranty/Quotation access and roles.
- New unified Audit Log aggregates Manager, Warranty and Quotation audit evidence with module filters.
- New System Settings center establishes the main portal as the platform configuration surface.
- Device & Security remains centralized at /device-setup.
- New System Health center checks Manager, Warranty and Quotation health/version plus PTM Root CA publication.
- Main Manager navigation exposes Administration rather than duplicating admin functions inside business modules.

## Warranty and Quotation become operational modules
- Warranty sidebar removes PC Setup & Security, Users & Access, Audit Log and System Settings.
- Warranty keeps Warranty-specific operational navigation and links back to PTM Home / Administration.
- Legacy Warranty Users/Audit/Settings entry points redirect to the central Manager equivalents where patched.
- Quotation legacy Admin Users/Audit/Settings routes redirect to central Manager equivalents.
- Business databases and module workflows remain in place; this release does not merge business DBs.

## UX direction
PTM Manager = platform.
Warranty = warranty operations.
Quotation = quotation operations.
One central identity/access/security/audit/health administration layer.

## Infrastructure
No Caddy, DNS, TLS, Tailscale or port changes. Boot-Safe Supervision retained.
